TSQR Calculation Logic

TSQR (Timely Submission of Quarterly Report) measures the timeliness of quarterly report submissions.
Formula: TSQR = (B ÷ A) × 100 where A = Due Date (days) and B = Actual Date (days)
Calculation: {{ calculation.actual_date|default:"0" }} ÷ {{ calculation.due_date|default:"0" }} × 100 = {{ calculation.achieved_value|floatformat:2|default:"0" }}%
Interpretation: {% if calculation.achieved_value <= 100 %} On-time or early submission {% else %} Late submission {% endif %}
