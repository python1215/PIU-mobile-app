About Access Types:

Access types define different permission levels and user roles within the project management system, controlling what actions users can perform.

  • Read Only: View access to project information without editing rights
  • Editor: Can create, edit, and update project records
  • Administrator: Full system access including user management
  • Reviewer: Can review and approve project submissions
  • Field Staff: Access for on-site data collection and reporting
  • Manager: Oversight access with reporting and analysis capabilities
  • Guest: Limited temporary access for external stakeholders
