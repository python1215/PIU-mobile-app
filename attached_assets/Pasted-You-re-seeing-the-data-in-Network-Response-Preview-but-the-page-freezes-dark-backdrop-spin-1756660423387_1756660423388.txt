You’re seeing the data in **Network → Response/Preview** but the page “freezes” (dark backdrop, spinner, no list) because of a markup/event mismatch between your page template and the HTMX response.

Here are the exact culprits in **your files** and the fixes:

---

# What’s going wrong (root causes tied to your code)

1. You open the Bootstrap modal **immediately on click** via `data-bs-toggle="modal"` / `data-bs-target="#contractSelectionModal"` on the button, while **HTMX is still fetching**. That shows the spinner, but if the incoming fragment is shaped like a *modal body* (or contains a `<script>`), Bootstrap’s focus trap/backdrop logic gets confused → looks like a freeze. (Button with both Bootstrap + HTMX on it is here.)&#x20;

2. Your HTMX view renders the partial **`project_actions/htmx/contract_selection_modal.html`** straight into `#contractModalBody`. If that partial still wraps its content in **`<div class="modal-body">…</div>`** or includes a `<script>`, you get a **nested `.modal-body`** (inside your real `.modal-body`) and a script that HTMX won’t run. That exact combo is the classic cause of “modal open + backdrop + nothing updates.” (This is the view that returns that template.)&#x20;

3. Your error handlers are bound on `document.body` and check `e.target.id === 'contractModalBody'`. On many HTMX events, `e.target` is the **trigger** (the button), not the **swap target**, so your friendly error UI won’t show—leaving the spinner up and the page feeling “stuck.” (See modal/error wiring in the page template.)&#x20;

---

# Minimal changes that stop the freeze

## A) Let HTMX finish, then open the modal

Either:

* **Option 1 (recommended):** remove Bootstrap’s auto-open from the button and open the modal on `htmx:afterSwap`.
* **Option 2:** keep auto-open, but **ensure the partial is fragment-only** (no `.modal-body`, no `<script>`).

### Option 1 (cleanest)

**Change your button** (remove the two Bootstrap attributes):

```html
<button type="button" 
        class="btn btn-outline-primary" 
        id="selectContractBtn"
        disabled
        hx-get="{% url 'project_actions:get_contracts_by_project_and_type_htmx' %}"
        hx-target="#contractModalBody"
        hx-vals='js:{"project_id": document.getElementById("id_project").value, "contract_type": document.getElementById("id_type_of_contract").value}'
        hx-trigger="click"
        hx-swap="innerHTML">
  <i class="bi bi-search me-1"></i>Select Contract
</button>
```



**Open the modal after the swap completes** (bind on the **target**, not the button):

```html
<script>
document.addEventListener('DOMContentLoaded', function () {
  const modalEl   = document.getElementById('contractSelectionModal');
  const modalBody = document.getElementById('contractModalBody');

  // Show a spinner as soon as the request starts (fires on the button or document)
  document.getElementById('selectContractBtn')
          .addEventListener('htmx:beforeRequest', function () {
            modalBody.innerHTML = '<div class="text-center p-4"><div class="spinner-border" role="status"></div><div class="mt-2">Loading…</div></div>';
          });

  // Open only AFTER the list is in the body
  modalBody.addEventListener('htmx:afterSwap', function () {
    bootstrap.Modal.getOrCreateInstance(modalEl).show();
  });

  // Robust error/timeout handlers
  modalBody.addEventListener('htmx:responseError', function () {
    modalBody.innerHTML = '<div class="alert alert-danger">Couldn’t load contracts. Try again.</div>';
    bootstrap.Modal.getOrCreateInstance(modalEl).show();
  });
  modalBody.addEventListener('htmx:timeout', function () {
    modalBody.innerHTML = '<div class="alert alert-warning">Request timed out. Try again.</div>';
    bootstrap.Modal.getOrCreateInstance(modalEl).show();
  });
});
</script>
```

(Your page already defines `#contractSelectionModal` and the single **real** `#contractModalBody`; keep that structure.)&#x20;

### Option 2 (keep auto-open)

If you prefer to keep `data-bs-toggle="modal"` and open immediately, then you **must** fix the partial (next section) so it doesn’t nest `.modal-body` or ship a `<script>`.

## B) Make your HTMX **partial** fragment-only

Your view renders **`project_actions/htmx/contract_selection_modal.html`**. Ensure that file returns **just** the list/header markup that belongs *inside* `#contractModalBody`—**no** `<div class="modal-body">…</div>`, **no** `<script>…</script>`. The view that renders this is here; the target is `#contractModalBody` in your page. &#x20;

Use a structure like:
