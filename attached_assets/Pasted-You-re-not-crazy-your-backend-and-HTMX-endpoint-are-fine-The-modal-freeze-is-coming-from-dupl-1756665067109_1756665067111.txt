You’re not crazy — your backend and HTMX endpoint are fine. The modal “freeze” is coming from **duplicate markup + conflicting open strategies in the same template**.

## The real culprits (in your template)

1. ### You have **multiple copies** of the modal scaffold (same IDs) in `contract_monitoring_form.html`

There are several repeated blocks with the exact same IDs `contractSelectionModal` and `contractModalBody`. When the page has duplicates, HTMX updates one `#contractModalBody` while Bootstrap opens **another** `#contractSelectionModal`. Result: the modal opens with a backdrop but appears “empty/frozen” even though the network response looks good. See the repeated modal blocks here (note the same IDs):   &#x20;

2. ### You also have **multiple copies of the Select button** (same ID) and at least one copy still uses **Bootstrap auto-open**

One version of the button **includes** `data-bs-toggle="modal"` + `data-bs-target="#contractSelectionModal"` (auto-opens immediately); other versions are HTMX-only. Mixing these leads to a race where the modal opens *before* the HTMX swap — often on the “other” duplicate modal — so you see the backdrop with no content. Here’s the copy that still auto-opens:&#x20;
…and a copy that doesn’t:&#x20;

3. ### An event listener is attached to the **wrong element** in one duplicate

One of the duplicates attaches `htmx:beforeRequest` to **`modalBody`**. HTMX lifecycle events bubble **up from the trigger** (the button), not sideways into unrelated nodes; `modalBody` won’t see `beforeRequest` from a button elsewhere. This doesn’t by itself freeze, but it’s another sign of duplicated, diverging logic:&#x20;

**JS (one block):**

```html
<script>
document.addEventListener('DOMContentLoaded', function() {
  const projectSelect    = document.getElementById('id_project');
  const contractTypeSelect = document.getElementById('id_type_of_contract');
  const selectBtn        = document.getElementById('selectContractBtn');
  const modalEl          = document.getElementById('contractSelectionModal');
  const modalBody        = document.getElementById('contractModalBody');

  // Enable / disable button
  function updateBtn(){ const ok = projectSelect?.value && contractTypeSelect?.value;
    selectBtn.disabled = !ok; selectBtn.classList.toggle('disabled', !ok); }
  projectSelect?.addEventListener('change', updateBtn);
  contractTypeSelect?.addEventListener('change', updateBtn);
  updateBtn();

  // Spinner at request start (listen on the trigger)
  selectBtn.addEventListener('htmx:beforeRequest', function () {
    modalBody.innerHTML = '<div class="text-center p-4"><div class="spinner-border" role="status"></div><div class="mt-2">Loading…</div></div>';
  });

  // Open after swap (listen on the TARGET)
  modalBody.addEventListener('htmx:afterSwap', function () {
    bootstrap.Modal.getOrCreateInstance(modalEl).show();
  });

  // Error/timeout fallbacks
  modalBody.addEventListener('htmx:responseError', function () {
    modalBody.innerHTML = '<div class="alert alert-danger">Couldn’t load contracts. Try again.</div>';
    bootstrap.Modal.getOrCreateInstance(modalEl).show();
  });
  modalBody.addEventListener('htmx:timeout', function () {
    modalBody.innerHTML = '<div class="alert alert-warning">Request timed out. Try again.</div>';
    bootstrap.Modal.getOrCreateInstance(modalEl).show();
  });
});

// Global so the HTMX fragment’s buttons can call it
function selectContract(contractRef){
  const input = document.querySelector('input[name="contract_refNo"]') || document.getElementById('id_contract_refNo');
  if (!input) return alert('Could not find contract reference field.');
  input.value = contractRef;
  bootstrap.Modal.getOrCreateInstance(document.getElementById('contractSelectionModal')).hide();
  input.dispatchEvent(new Event('change', { bubbles: true }));
}
</script>
```

(These match the “good” code paths you already have; the key is **removing the duplicates/conflicts**.) &#x20;

### Why this explains “Network → Preview shows correct content”

The HTMX response is correct and the swap **does** happen — just not into the modal you’re looking at. With duplicate IDs, the browser picks the **first** `#contractModalBody` for the selector, while Bootstrap may be showing **another** `#contractSelectionModal`. That’s exactly why you see the data in the network preview but the popup looks empty/frozen. Cleaning the duplicates resolves it. &#x20;
