# Windows SSH Config Fix for Replit VS Code Connection

## Current Issue
VS Code is trying to use PowerShell on Linux server, causing "powershell: command not found" error.

## SSH Config File Location (Windows)
%USERPROFILE%\.ssh\config

## Updated SSH Config Content
Host *.replit.dev
    Port 22
    IdentityFile ~/.ssh/replit
    StrictHostKeyChecking accept-new
    RemoteCommand bash
    RequestTTY no

Host replit-piu
    HostName 88ef5e6b-ff4f-47ab-b937-c85b713020fa-00-cu5w6mikd1gh.worf.replit.dev
    User 88ef5e6b-ff4f-47ab-b937-c85b713020fa
